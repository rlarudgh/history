## 상세 내용

옐로시스 웹과 하이브리드 앱 동시에 사용 가능한 신규 프로젝트입니다.

### 구현 내용

- **모든 페이지 퍼블리싱**: 모든 페이지 퍼블리싱 및 API 연동
- **개발 생산성 도구 구축**:
  - `.claude/commands/create-feature`: FSD 구조에 맞는 기능 자동 생성 명령어
  - `.claude/commands/generate-tests`: 컴포넌트 테스트 파일 자동 생성 도구
- **포괄적인 개발 문서**: PRD, 시스템 플로우, API 문서, 웹뷰 통합 가이드, 개발 가이드, 상태 관리 문서, 테스트 가이드, 배포/보안/성능 최적화 가이드

### 성과

1. **코드 품질 자동화 시스템 구축**
   - Biome을 통한 자동 린팅 및 포맷팅 설정
   - Husky을 이용한 pre-commit 훅으로 코드 품질 사전 검증
   - lint-staged 설정으로 스테이지된 파일만 자동 검사/포맷팅

2. **아직 WIP(진행중)인 프로젝트입니다**
